# Настройка Amvera

## Переменные окружения

В разделе **Настройки → Переменные окружения** добавьте:

| Переменная | Описание |
|------------|----------|
| `VITE_GOOGLE_API_KEY` | API ключ Google Gemini (или `GOOGLE_API_KEY`) |

## Как это работает

- **Docker** собирает образ: `npm run build` → статика в `dist/`
- **Node.js сервер** (`server.js`) раздаёт статику и проксирует `/api/google/*` на Google Gemini API
- API ключ хранится в env и не попадает в клиентский код
